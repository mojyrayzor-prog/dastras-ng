# DastRas NG

کلاینت اندروید مبتنی بر Xray (Flutter + libXray).

## ساخت APK بدون نصب هیچ چیزی
1. در گیت‌هاب یک ریپوی جدید بسازید (New repository).
2. همه‌ی فایل‌های این پوشه (از جمله پوشه‌ی `.github`) را آپلود کنید.
3. به تب **Actions** بروید و workflow به نام «Build DastRas NG APK» را اجرا کنید (Run workflow).
4. بعد از چند دقیقه، فایل APK را از بخش **Artifacts** همان اجرا دانلود کنید.

اگر خطا داد، متن لاگ قسمت قرمز را برای من بفرستید.
